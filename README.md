# 🎓 FacultyPro - Smart Faculty Management System

![Version](https://img.shields.io/badge/version-v6.0--stable-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![Status](https://img.shields.io/badge/status-Production%20Ready-success)

**FacultyPro** is a modern, offline-first Android application designed to streamline academic management for faculties. Built with **AI-Assisted Development**, it empowers educators to manage attendance, analyze student performance, and generate reports—all without needing an active internet connection.

---

## 🚀 Key Features

### 1. 📱 Offline-First Architecture

- **No Internet? No Problem:** All data is stored locally using **IndexedDB** & **localStorage**.
- **Data Sovereignty:** Your data stays on your device. Complete privacy and ownership.

### 2. 📊 Advanced Analytics & Insights

- **Visual Dashboard:** Real-time graphs for attendance trends and class performance.
- **Student Profiling:** Detailed drill-down into individual student history.
- **Risk Detection:** Automatically identifies students with low attendance (Red/Orange zones).

### 3. 📝 Smart Attendance System

- **Quick Toggles:** Mark attendance in seconds with an intuitive interface.
- **Batch Operations:** Manage entire classes effortlessly.
- **Edit History:** Correct past records with a secure audit trail.

### 4. 📄 One-Click Reporting

- **Multi-Format Export:** Generate detailed reports in **PDF** and **Word (DOCX)** formats.
- **Intervention Letters:** Auto-generate letters for parents/guardians for low-attendance students.

### 5. 🛠️ Power Tools

- **Backup & Restore:** Securely backup entire database to a single JSON file.
- **Theme Engine:** Beautiful Dark/Light modes with dynamic color accents.
- **Security:** Built-in license verification and secure role management.

---

## 🛠️ Technology Stack

- **Core:** Vanilla JavaScript (ES6+), HTML5
- **Styling:** TailwindCSS (Utility-first)
- **Storage:** IndexedDB (Heavy lifting), LocalStorage (Settings)
- **Platform:** Android (WebView Wrapper)
- **Development:** AI-Assisted Engineering
