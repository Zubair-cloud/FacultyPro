# Dhanalakshmi Srinivasan University - Assets Folder

## 📁 Folder Structure

This folder contains all DSU-specific branding and configuration files.

### Place Your Assets Here:

#### 📸 Logos (in `/logos/` folder)

- `logo.png` - Main university logo (transparent PNG, 512x512px recommended)
- `logo-small.png` - Small icon version (128x128px)
- `app-icon.png` - App launcher icon (512x512px, square)

#### 🎨 Theme Files (in this folder)

- `config.json` - DSU configuration (colors, fonts, features)
- `theme.css` - Optional custom CSS overrides
- `background.jpg` - Optional background image

---

## 📋 Instructions

1. **Drop your university logo** into the `logos/` folder
2. **Name it:** `logo.png`
3. **Format:** PNG with transparent background
4. **Size:** At least 512x512 pixels

**Optional files:**

- App icon (for launcher): `app-icon.png`
- Custom background: `background.jpg`

---

## ✅ Ready!

Once you add the logo, we'll update the configuration to use it.
